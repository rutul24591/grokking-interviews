# Search in Rotated Sorted Array — Example 1 (Less Optimized: Linear Scan)

LeetCode: https://leetcode.com/problems/search-in-rotated-sorted-array/

## Approach
Scan all indices and return the first match.

## Complexity (step-by-step)
1. Visit each element once in the worst case (n checks): O(n).
2. Constant-time equality check per element: O(1).

## Overall Complexity
- Time: O(n)
- Space: O(1)
