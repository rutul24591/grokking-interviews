# Two Sum — Example 1 (Less Optimized: Brute Force)

LeetCode: https://leetcode.com/problems/two-sum/

## Approach
Nested loops over all pairs.

## Complexity (step-by-step)
1. Try every pair (i, j): O(n^2) comparisons.
2. Return immediately when nums[i] + nums[j] == target.
## Overall Complexity
- Time: O(n^2)
- Space: O(1)
