# Climbing Stairs — Example 2 (More Optimized: Iterative DP)

LeetCode: https://leetcode.com/problems/climbing-stairs/

## Approach
Compute the recurrence iteratively while keeping only the previous two values.

## Complexity (step-by-step)
1. Single loop from 3..n: O(n).
2. Constant-time arithmetic each iteration.

## Overall Complexity
- Time: O(n)
- Space: O(1)
