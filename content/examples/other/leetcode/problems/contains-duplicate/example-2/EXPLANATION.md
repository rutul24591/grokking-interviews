# Contains Duplicate — Example 2 (Optimized: Hash Set)

LeetCode: https://leetcode.com/problems/contains-duplicate/

## Approach
Track seen elements with a set.

## Complexity (step-by-step)
1. Insert each element into a hash set: O(1) average per insert.
2. If element already exists, duplicate found.
## Overall Complexity
- Time: O(n) average
- Space: O(n)
