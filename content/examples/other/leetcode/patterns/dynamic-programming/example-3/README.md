# Dynamic Programming — Edge Cases

Covers amount=0, empty coin sets, and negative/invalid inputs.

## Files
- `EXPLANATION.md`
- `demo.js`
- `README.md`

## Run
`node content/examples/other/leetcode/patterns/dynamic-programming/example-3/demo.js`

## What to Verify
- amount=0 returns 0
- empty coins => -1 for amount>0
- negative amounts should be rejected by policy
