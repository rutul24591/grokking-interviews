# Monotonic Stack — Next Greater Element Workbench

Implements a monotonic decreasing stack to compute next-greater elements in O(n).

## Files
- `EXPLANATION.md`
- `pattern.js`
- `app.js`
- `README.md`

## Run
`node content/examples/other/leetcode/patterns/monotonic-stack/example-1/app.js`

## What to Verify
- stack holds indices in decreasing value order
- each index is pushed and popped at most once
- unresolved items stay -1
