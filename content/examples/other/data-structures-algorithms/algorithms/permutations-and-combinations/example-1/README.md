# Permutations And Combinations — Permutation Generator Workbench

Implements backtracking to generate all permutations of a small set (bounded by factorial growth).

## Files
- `EXPLANATION.md`
- `algorithm.js`
- `app.js`
- `README.md`

## Run
`node content/examples/other/data-structures-algorithms/algorithms/permutations-and-combinations/example-1/app.js`

## What to Verify
- each permutation uses each element exactly once
- branching explores swap/choose-based recursion
- output size matches n! for unique elements
