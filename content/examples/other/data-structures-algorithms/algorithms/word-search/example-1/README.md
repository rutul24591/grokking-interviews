# Word Search — Grid Search Workbench

Implements DFS backtracking over a grid to find a word with adjacency constraints.

## Files
- `EXPLANATION.md`
- `algorithm.js`
- `app.js`
- `README.md`

## Run
`node content/examples/other/data-structures-algorithms/algorithms/word-search/example-1/app.js`

## What to Verify
- visitation marking prevents reusing the same cell
- search explores 4-direction adjacency
- returns true on match and false otherwise
