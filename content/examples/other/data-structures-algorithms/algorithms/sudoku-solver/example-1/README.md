# Sudoku Solver — Sudoku Solver Workbench

Implements a backtracking Sudoku solver and solves a small puzzle grid.

## Files
- `EXPLANATION.md`
- `algorithm.js`
- `app.js`
- `README.md`

## Run
`node content/examples/other/data-structures-algorithms/algorithms/sudoku-solver/example-1/app.js`

## What to Verify
- validity checks gate candidate placements
- solver backtracks when constraints are violated
- returns a solved grid or null
