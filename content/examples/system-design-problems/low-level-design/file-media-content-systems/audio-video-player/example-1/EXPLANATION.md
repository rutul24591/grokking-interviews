Example 1 models a production A/V player:

- Playback state machine (idle → loading → playing/paused → ended/error)
- Buffering and stall detection hooks
- Tracks: captions/subtitles and audio tracks model
- Keyboard shortcut mapping model

Interview focus:
- Adaptive streaming (HLS/DASH) strategy and DRM integration points
- Handling autoplay policies and user gesture requirements
